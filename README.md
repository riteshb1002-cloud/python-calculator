# Python Calculator CLI App

## Task 1 - Python Developer Internship

This project is a command-line calculator application developed using Python.

## Features

The calculator supports the following operations:

- Addition
- Subtraction
- Multiplication
- Division
- Exit option

## Technologies Used

- Python
- VS Code
- Command Line / Terminal

## Concepts Used

- Functions
- Loops
- Conditional statements
- User input
- Exception handling

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

```bash
python calculator.py
